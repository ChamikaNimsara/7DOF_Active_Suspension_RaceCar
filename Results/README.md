# Results

Saved numerical evidence is grouped by analysis phase:

- `Passive` — passive baseline, bump, kerb and frequency-response metrics.
- `Skyhook` — active/passive comparisons and Skyhook tuning results.
- `LQR` — state-space, controllability, controller-design and LQR tuning results.
- `Robustness` — parameter-sensitivity and controller robustness results.
- `Operating_Envelope` — speed, high-speed kerb, suspension working-range and tyre-contact indicators.
- `Final` — consolidated Passive vs Skyhook vs LQR benchmarks.

CSV and text files provide human-readable evidence. MAT files retain MATLAB data required by downstream scripts.
