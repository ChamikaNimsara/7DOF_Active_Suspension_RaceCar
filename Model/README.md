# Simulink Model

`RaceCar_7DOF_ActiveSuspension.slx` is the validated full-vehicle model. It contains the passive plant, active actuator interface, controller selection and the implemented Skyhook/LQR control paths.

Run `setup_project.m` and `Scripts/01_Parameters/vehicle_parameters.m` before opening or simulating the model. Generated Simulink cache files are intentionally excluded from version control.
